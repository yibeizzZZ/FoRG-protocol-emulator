# FoRG architecture and ISA specification

This document is the contract between firmware, the Python golden model in
`sim/forg`, and the RTL. If the RTL and the model disagree, one of them is
wrong with respect to this file.

## Block diagram

```
            host SPI link (ui0..2, uo7)
                     |
          +----------+-----------+
          |  register map / imem |  64 x 16-bit shared instruction memory
          +--+-----+-----+-----+-+
             |     |     |     |
           SM0   SM1   SM2   SM3     each: X, Y, ISR, OSR, 4-deep TX/RX FIFOs,
             |     |     |     |     fractional clock divider, line unit, CRC
          +--+-----+-----+-----+-+
          |  GPIO: out / oe / od |  2-flop input sync (per-pin bypass)
          +----------------------+
             uio0-7  uo0-7  ui0-7
```

## Pins

| logical pin | pad      | direction     | notes                                |
|-------------|----------|---------------|--------------------------------------|
| 0-7         | uio[0:7] | bidirectional | open-drain capable (`od` mask)       |
| 8-15        | uo[0:7]  | output only   | always driven; uo7 = host MISO       |
| 16-23       | ui[0:7]  | input only    | ui0-2 = host SCK/MOSI/CS             |

Pin groups wrap modulo 24. Outputs are registered: a value written in cycle
`t` is on the pad in cycle `t+1`. Inputs pass through 2 synchronizer flops
unless the pin is in `sync_bypass`, so an SM sees the pad value from cycle
`t-2`. Open-drain pins drive low when the output bit is 0 and release when
it is 1, so I2C firmware never touches pin directions.

When several SMs write the same pin in one cycle, the highest-numbered SM
wins.

## State machine

Each SM executes one instruction per tick. A tick is generated by a 16.8
fixed-point divider (`clkdiv`): the accumulator adds 256 every system clock
and ticks when it reaches `clkdiv * 256`.

Every instruction takes exactly `1 + delay` ticks unless it stalls. Stalling
instructions do not start their delay until they complete. This is what makes
the static timing proofs (`.assert_cycles`) sound.

Side-set is applied every time an instruction issues, including stalled
retries, so a pin can be held at a defined level while waiting.

### Registers

| name  | width | notes                                                     |
|-------|-------|-----------------------------------------------------------|
| PC    | 6     |                                                           |
| X, Y  | 32    | scratch, loop counters                                    |
| ISR   | 32    | input shift register + 6-bit count                        |
| OSR   | 32    | output shift register + 6-bit count (32 = empty)          |
| CRC   | <=32  | bit-serial CRC/LFSR, configurable width/poly/init/reflect |
| STATUS| 16    | see below, read via `mov x, status`                       |

### Configuration (per SM, written by host before enabling)

| key                         | meaning                                              |
|-----------------------------|------------------------------------------------------|
| `clkdiv`                    | 1.0 to 65535.996, fractional                         |
| `out_base`, `out_count`     | OUT/MOV PINS group, also line unit TX pin            |
| `set_base`, `set_count`     | SET PINS group                                       |
| `side_base`                 | side-set group (width from `.side_set`)              |
| `in_base`                   | IN/MOV/WAIT-relative pin 0, line unit RX pin         |
| `jmp_pin`                   | absolute pin for `jmp pin`                           |
| `in_shift`, `out_shift`     | `left` (MSB first) or `right` (LSB first)            |
| `autopush`, `push_thresh`   | push ISR when count reaches threshold                |
| `autopull`, `pull_thresh`   | refill OSR when count reaches threshold              |
| `timeout`, `trap`           | stall longer than `timeout` ticks jumps to `trap`    |
| `crc_*`                     | width, poly, init, reflect, src (`none`/`in`/`out`)  |
| `line_*`                    | line unit, see below                                 |
| `pindirs`, `pins`, `od`     | initial pin directions, levels, open-drain mask      |
| `sync_bypass`               | pins that skip the input synchronizer                |

## Instruction encoding

```
 15  13 12     9 8                 0
+------+--------+-------------------+
|  OP  |   DS   |        ARG        |
+------+--------+-------------------+
```

`DS` holds side-set in its top `side_count` bits (0 to 2) and delay in the
rest, so delay is 0-15, 0-7 or 0-3.

| OP | mnemonic | ARG layout                                          |
|----|----------|-----------------------------------------------------|
| 0  | `jmp`    | cond[8:6] addr[5:0]                                 |
| 1  | `wait`   | pol[8] src[7:6] resync[5] index[4:0]                |
| 2  | `in`     | src[8:6] count[4:0] (0 = 32)                        |
| 3  | `out`    | dst[8:6] count[4:0] (0 = 32)                        |
| 4  | `push`, `pull`, `ctl`, `irq` | sub[8:7], see below         |
| 5  | `mov`    | dst[8:6] op[5:4] src[2:0]                           |
| 6  | `cap`, `add` | `cap`: [8]=0 pins-1[2:0]; `add`: [8]=1 reg[7] imm7[6:0] |
| 7  | `set`    | dst[8:6] imm[4:0]                                   |

### Operands

- `jmp` conditions: always, `!x`, `x--`, `!y`, `y--`, `x!=y`, `pin`, `!osre`.
  `x--`/`y--` test for non-zero, then decrement. `!osre` is true while the OSR
  holds fewer than `pull_thresh` consumed bits.
- `wait` sources: `gpio` (absolute pin), `pin` (relative to `in_base`), `irq`
  (waiting for 1 clears the flag), `edge` (true once the pin has been seen at
  `!pol` and then `pol` during this wait). With `resync`, the condition is
  checked every system clock instead of every tick, and the divider phase is
  reset when it completes. This cuts UART RX sampling error from one tick to
  one clock.
- `in` sources: `pins`, `x`, `y`, `null`, `isr`, `osr`, `line`.
- `out` destinations: `pins`, `x`, `y`, `null`, `pindirs`, `pc`, `isr`, `line`.
- `mov` destinations: `pins`, `x`, `y`, `pindirs`, `pc`, `isr`, `osr`, `crc`;
  sources: `pins`, `x`, `y`, `null`, `status`, `isr`, `osr`, `crc`;
  operations: none, `~` (invert), `::` (bit reverse).
- `set` destinations: `pins`, `x`, `y`, `pindirs`.

### OP 4 sub-operations

| sub | form                              | bits                                  |
|-----|-----------------------------------|---------------------------------------|
| 0   | `push [iffull] [block\|noblock]`  | iffull[6] block[5]                    |
| 1   | `pull [ifempty] [block\|noblock]` | ifempty[6] block[5]                   |
| 2   | `ctl <flags>`                     | flush[5] rx_stop[4] drain[3] rx_arm[2] tx_reset[1] crc_reset[0] |
| 3   | `irq set\|wait\|clear <n>`        | clear[6] wait[5] index[2:0]           |

`ctl drain` stalls until the line serializer is idle, including any pending
stuff bit. `ctl flush` empties the OSR and clears the ISR.

### CAP

`cap n` samples `n` pins from `in_base` once per tick. While the sample is
unchanged it counts; on change (or count saturation at 2^24-1) it pushes
`{count[31:8], previous_level[7:0]}` without blocking. On overflow it sets
STATUS bit 6 and drops the word. A one-instruction wrap loop is a
run-length-compressed logic analyzer.

### STATUS

| bit | name        | meaning                                |
|-----|-------------|----------------------------------------|
| 0   | TXF_EMPTY   | TX FIFO empty                          |
| 1   | RXF_FULL    | RX FIFO full                           |
| 2   | TIMEOUT     | last trap was a stall timeout (sticky) |
| 3   | RX_EOP      | line RX stopped on SE0 (sticky)        |
| 4   | RX_STUFF_ERR| line RX saw a stuffing violation       |
| 5   | RX_OVF      | line RX bit buffer overflowed          |
| 6   | RXF_OVF     | non-blocking push or CAP dropped data  |
| 7   | RX_ACTIVE   | line RX armed                          |
| 15  | MARKER      | always 1, so status words pushed into the RX FIFO can be told apart from data |

## Line unit

The line unit runs on the system clock with its own bit-period counter
(`line_period` cycles). Firmware feeds or drains up to 32 bits at a time and
can do other work while bits are on the wire.

TX (`out line, n`): stalls until the bit queue is empty, then loads `n` bits.
CRC snooping (`crc_src out`) happens at load time, so `ctl crc_reset` right
after loading a header excludes that header from the CRC. Per bit:

1. Bit stuffing (`line_stuff N`): after N consecutive 1s (`line_stuff_mode
   ones`, USB) or N identical bits (`any`, CAN) a complement bit is inserted.
2. NRZI (`line_nrzi`): 0 toggles the level, 1 keeps it.
3. Manchester (`line_manchester`): the first half of the bit is the inverse
   level, the second half the true level (IEEE 802.3 polarity).
4. Output on `out_base`; with `line_diff`, `out_base + 1` gets the complement.

RX (`ctl rx_arm`, then `in line, n`): hunts for a transition away from
`line_idle`, then samples at mid-bit and re-aligns on every transition. NRZI
decode, destuffing and CRC snooping (`crc_src in`) happen in hardware. With
`line_se0`, both `in_base` and `in_base + 1` low at a sample point stops the
receiver and sets RX_EOP. `in line` on a stopped receiver jumps straight to
`trap`, so packet framing needs no polling.

## Timing assertions

```
.assert_cycles <from> <to>[|<to2>...] <n>       ; exactly n ticks
.assert_cycles <from> <to> <min> <max>          ; range
```

The assembler-side analyzer (`forg/timing.py`) enumerates every control-flow
path from `from` to the first arrival at any `to` label. Each instruction
costs `1 + delay`. Stalling instructions on the path are reported, and the
bound assumes they do not stall. Unbounded loops and computed jumps fail the
assertion.

## Host interface

The silicon exposes a SPI target on ui0-2/uo7 with a register map for imem
writes, SM config, FIFO access and IRQ flags. The simulator models it at the
transaction level: `Chip.load`, `Chip.put`, `Chip.get`, `Chip.exec`.

## Differences from RP2040 PIO

| feature                         | PIO                    | FoRG                                    |
|---------------------------------|------------------------|-----------------------------------------|
| bit stuffing / NRZI / Manchester| firmware               | line unit, hardware                     |
| CRC                             | none (CPU or DMA)      | per-SM bit-serial CRC, snooped          |
| serializer timing               | instruction loop       | independent bit counter, firmware async |
| open drain                      | pindirs trick          | per-pin `od`, plain `set`/`out`         |
| stall timeout                   | none                   | `timeout` + `trap`                      |
| edge wait                       | level only             | `edge`, plus divider `resync`           |
| logic capture                   | firmware loop          | `cap` run-length instruction            |
| arithmetic                      | decrement only         | `add x/y, imm7`                         |
| timing verification             | none                   | static `.assert_cycles` proofs          |
